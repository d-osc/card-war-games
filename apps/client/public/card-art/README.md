# โฟลเดอร์ภาพอาร์ตการ์ด (card-art)

วางไฟล์ภาพที่นี่เพื่อให้การ์ดแต่ละใบแสดง **ภาพจริง** แทนไอคอน/อีโมจิกลางการ์ด

## วิธีใช้

1. ตั้งชื่อไฟล์ตรงกับ `templateId` ของการ์ด เช่น
   - `sword_wood.png` → การ์ด "ดาบไม้"
   - `ore_iron.png` → การ์ด "แร่เหล็ก"
2. รีเฟรชหน้าเว็บ — การ์ดจะแสดงภาพอัตโนมัติ (ไม่ต้องแก้โค้ด)

## รูปแบบที่รองรับอัตโนมัติ

- `/card-art/<templateId>.png` (สำรอง .png เท่านั้นสำหรับไฟล์วางเอง)
- ถ้าต้องการใช้ .svg/.jpg หรือ URL อื่น ให้ระบุใน `image` ของ template
  ที่ `packages/shared/src/cards.ts` เช่น `image: '/card-art/gem_diamond.svg'`

## ขนาดแนะนำ

- หน้าต่างอาร์ตกว้าง 320 × สูง 236 (อัตราส่วน ~4:3)
- ภาพจะถูกครอปแบบ cover (`preserveAspectRatio: xMidYMid slice`)
- ไฟล์ตัวอย่างในโฟลเดอร์นี้เป็น .svg ขนาด 640×472

## ลำดับการแสดงผล

1. `template.image` (ถ้าระบุ)
2. `/card-art/<templateId>.png` (ถ้าไฟล์มีจริง)
3. ไอคอนเวกเตอร์ตามประเภทการ์ด (เหมือนเดิม)
4. อีโมจิของการ์ด
